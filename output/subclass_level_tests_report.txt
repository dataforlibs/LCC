TEST 1 [Subclass-level, n~115]  Baconian group vs. growth factor
H0: growth factor distributions are equal across Memory / Reason / Imagination
H1: at least one Baconian group grew faster (hierarchy persistence predicts
    Memory or Reason — the groups Jefferson privileged — grew more)
Restricted to subclasses with >=50 cumulative records by 1815
----------------------------------------------------------------------
  n = 115 subclasses with usable growth factors
  (87 excluded with <50 records by 1815)

  Memory        n= 56  mean=     274x  median=     189x  range=[4, 1897]
  Reason        n= 37  mean=     363x  median=     159x  range=[8, 2717]
  Imagination   n= 22  mean=     408x  median=     306x  range=[24, 1421]

  Shapiro-Wilk Memory        : W=0.684, p=0.0000 (NON-NORMAL)
  Shapiro-Wilk Reason        : W=0.555, p=0.0000 (NON-NORMAL)
  Shapiro-Wilk Imagination   : W=0.818, p=0.0010 (NON-NORMAL)
  Levene: F=0.986, p=0.3764 (equal variances)

  Kruskal-Wallis:  H=3.930,  p=0.1402  [primary]
  ANOVA (check):   F=0.950,  p=0.3896
  Effect size: eta-squared = 0.017 (small)

  RESULT: NOT SIGNIFICANT (p=0.1402)
  Highest-growth group: Imagination (mean 408x)
  H0 retained. No Baconian group shows significantly higher growth.

  NOTE on subclass-level inheritance: all subclasses within a parent class
  share the same Baconian group. Variation within each group reflects
  different subclass sizes and coverage trajectories. Effective independent
  observations per group are bounded by the number of parent classes,
  not the number of subclasses. Power is substantially higher than n=21
  but should not be treated as equivalent to 115 independent units.

  METHODOLOGICAL CAVEATS:
  1. Pseudo-replication: jeff_ch is a class-level step function with
     only ~7 distinct values after correction. All subclasses of the
     same parent class share one chapter count. Effective df for this
     correlation is closer to 7 than to n_jeff. Per-chapter descriptives
     above are a more reliable primary evidence source.
  2. Geographic hierarchy ambiguity: ch.29 Geography (G class, now
     corrected to 'Reason') has 5 sub-entries (General/Europe/Asia/Africa/
     America) each mapping to different LCC subclasses. This means the
     chapter count for G subclasses is inherently ambiguous at the
     subclass level — a limitation of the Jefferson classification itself.
  3. The primary test of the suppression hypothesis is Test 4 (ABSENT vs
     classified), which uses the binary status variable assigned at the
     subclass level — not this correlation.
